Ausführliche Erklärung der Datei style.css

Das Stylesheet definiert Farben/Typografie, das Seiten‑Layout (Header/Main/Footer), Komponenten wie Buttons und Statusboxen sowie das Overlay‑Popup. Es ist für die Viewer‑Seite (index.html) und die Live‑AR‑Seite (live.html) ausgelegt.

1. Design‑Variablen & Grundstruktur

:root { --accent: #F39205; --bg: #ffffff; --border: rgba(0,0,0,0.08); --muted: #4b5563; --text: #212121; }
* { box-sizing: border-box; }
html, body { height: 100%; margin: 0; }
body {
  background: var(--bg); color: var(--text);
  display: grid; grid-template-rows: auto 1fr auto; min-height: 100dvh;
  font-family: ui-sans-serif, system-ui, -apple-system, Segoe UI, Roboto, Helvetica, Arial;
  overflow: hidden;
}
  • Variablen: Farbpalette über --accent, --bg, --text, --muted und --border.
  • Box‑Sizing: Einheitliches border-box verhindert unvorhersehbares Padding/Layout.
  • Grid‑Layout: Seite besteht aus drei Reihen: Header, Inhalt, Footer.
  • Schrift: System‑UI Schriftfamilie für konsistente Darstellung.

2. Header

header { background:#fff; border-bottom:1px solid #d0d0d0; position: sticky; top:0; z-index:10; text-align:center; }
.header-inner { display:flex; align-items:center; justify-content:center; gap:18px; max-width:1200px; margin:0 auto; padding:16px 20px; }
.site-title { font-weight:700; line-height:1.1; font-size: clamp(20px,3vw,28px); text-align:left; white-space: nowrap; }
.logo { height: clamp(40px,4.3vw,60px); width:auto; }
  • Sticky: Header bleibt oben kleben (position:sticky).
  • Typografie: Responsive Größen via clamp, linksbündiger Titel.
  • Layout: .header-inner zentriert die Inhalte, maximalbreite 1200px.

3. Hauptbereich & Szene

main { background: var(--bg); position:relative; min-height:0; }
main.main-transparent { background: transparent !important; }
#content-preview { position:absolute; inset:0; background: var(--bg); }
main.main-transparent #content-preview { background: transparent !important; }
a-scene { display:block; width:100%; height:100%; background: transparent !important; touch-action: none; }
  • Transparenz‑Modus: Klasse .main-transparent macht den Hintergrund (main und #content-preview) transparent – wichtig für AR Kamera‑Feed.
  • Canvas‑Gesten: touch-action:none verhindert Browservorgaben und erlaubt eigene Gestensteuerung.
  • Flächendeckend: Szene und #content-preview spannen sich über die gesamte Fläche (inset:0, 100%).
